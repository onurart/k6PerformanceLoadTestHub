# k6PerformanceLoadTestHub

HTTP tabanlı, güvenli sınırlar ve otomatik durdurma eşikleri içeren k6 kapasite testi paketi.

## Kullanım

Test hedefini, senaryoyu ve limitleri `config.env` dosyasında ayarlayın:

```bash
./baslat.sh
```

Ayrıntılı kullanım, dağıtık test ve sonuç yorumlama için [k6_test_docs.md](k6_test_docs.md) dosyasına bakın.
